D. Sliders (easy version) 题解

发表于2026-08-17|更新于2026-09-15
|浏览量:

题意

数轴上有 n 个滑块，第 i 个滑块初始位置为 a[i]（严格递增）。滑块不能互相越过，相邻滑块间距恒 $\ge 1$。

一次操作「把滑块 id 移到位置 x」会带动相邻滑块：

  • 向右移（x > a[id]）：a[id]=x，然后对 j = id+1..n 依次 a[j] = max(a[j], a[j-1]+1)。
  • 向左移（x < a[id]）：a[id]=x，然后对 j = id-1..1 依次 a[j] = min(a[j], a[j+1]-1)。

给定 m 个操作，等概率随机重排后依次执行。回答 q 次询问：某滑块最终位置的期望值，对 1e9+7 取模。

数据范围：$\sum n\le 10^6,\ \sum m\le 3\cdot 10^3,\ \sum q\le 3\cdot 10^3$。

核心思路

1. 坐标变换：消除“间距 1”的约束

令 c[i] = a[i] - i。初始 a 严格递增保证 c 序列非递减。

对一次操作（设 v = x - id），在 c 坐标下的效果是：

  • 向右（v > c[id]）：c[j] = max(c[j], v) 对所有 j >= id。
  • 向左（v < c[id]）：c[j] = min(c[j], v) 对所有 j <= id。

推导（以向右为例）：更新 t[j] = max(s[j], t[j-1]+1)，代入 c[j]=t[j]-j：

展开到 id 处（c[id] 被设为 v），结合 c 非递减，得 c[j] = max(c[j]^{old}, v)。向左对称。

2. 关键观察：每个滑块的演化互相独立

固定滑块 k，考察操作 (i, x)（v = x - i）对 c[k] 的影响：

关系 影响
i < k 恒为 c[k] = max(c[k], v)（向上推）
i > k 恒为 c[k] = min(c[k], v)（向下压）
i = k 恒为 c[k] = v（直接设置）

证明（以 i < k 为例）：操作向右（v > c[i]）时 c[k] = max(c[k], v)；操作向左（v <= c[i]）时 c[k] 不变。而 c 非递减有 c[i] <= c[k]，故 v <= c[i] <= c[k] 时 max(c[k], v) = c[k]，两种情形统一为 max(c[k], v)。

因此 c[k] 的最终值只由三类值决定，无需追踪其它滑块：上推集合 U = {v : i<k}、下压集合 D = {v : i>k}、赋值集合 S = {v : i=k}。

3. 子问题：随机排列下 max/min/set 的期望

给定初始值 c0，up 集合（c=max(c,v)）、down 集合（c=min(c,v)）、set 集合（c=v），全部操作随机排列，求 E[c]。

阈值分析：对固定阈值 t，只看状态 [c >= t]。

  • up(v) 且 v >= t：强制状态变为 $\ge t$。
  • down(v) 且 v < t：强制状态变为 $< t$。
  • set(v) 且 v >= t：强制 $\ge t$；set(v) 且 v < t：强制 $< t$。
  • 其余操作不改变状态。

设

  • A(t) = #{up v >= t} + #{set v >= t}
  • B(t) = #{down v < t} + #{set v < t}

最终状态由最后一个属于 A(t) ∪ B(t) 的操作决定：最后一个若是 A 类则 c >= t，否则 c < t；若两类都不存在，则保持初始 [c0 >= t]。

复杂度

每个询问需 O(m) 分类 + O(m log m) 排序与扫描。总复杂度 $O(\sum n + \sum q\cdot m\log m)$，在 $\sum m,\sum q\le 3000$ 下约为 $10^8$，实测最坏数据约 0.93 秒。
