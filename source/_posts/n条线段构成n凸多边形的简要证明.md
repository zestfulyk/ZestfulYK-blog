# 前提条件

$$n\geq3$$
边长为正

# 充要条件

最长的那条线段的长度,小于,其他线段的长度之和

# 必要性

这个很好理解,只要划分成三角形,把不等式传递使用就行

或者说,折线长度大于直线段

# 充分性

这涉及到一个更强的结论,那么我们证明这个结论就行:

# 更强的结论

如果满足这个前文提到的充要条件,那么一定能构造一个圆内接凸多边形

要构造圆内接多边形，只需找到半径 R 使圆心角之和为 2π

下面证明这样的 R 存在

# 更强的结论的证明

为了证明我们的构造能够成立,那么我们需要证明下面这个求和函数的值等于$2\pi$

$$\sum_{i=1}^n \theta_i=2\pi$$
要是这个结论成立,那么就能说明我们的构造是存在的,就能证明开头的条件是充分必要的了

因此,我们需要对这个函数进行分析

# 对子问题函数的分析

这个函数的计算并不容易,因为条件给的是边的长度,而我们需要的是角度,所以我们需要一步转换
这个转换就是弦长和圆心角的关系

$$a_i=2R\sin\left(\frac{\theta_i}{2}\right)$$
显然圆的半径R一定大于等于最大弦长的一半,

设最大值为M,所以自变量R的范围是:
$$R\geq \frac{M}{2}$$
假设每条弦取的圆心角都是劣弧所对的圆心角
那么我们就可以设
$$f(R)=\sum_{i=1}^n\theta_i=2\sum_{i=1}^n\arcsin\left(\frac{a_i}{2R}\right)$$
接下来我们需要分析一下函数的单调性,连续性和边界

由于arcsin函数是连续的,所以f也是连续的

当
$$R\in\left[\frac{M}{2},+\infty\right]$$
时,由于arcsin逐项递减,所以求和后的f(R)严格单调递减

最后是边界,

当R趋向于正无穷时
$$\lim_{R\to\infty}f(R)=0$$
当
$$R=\frac{M}{2}$$
时
$$\lim_{R\to\frac{M}{2}}f(R)=\pi+2\sum_2^{n-1}\arcsin(\frac{a_i}{M})$$
但是函数在初始点的取值并不一样,所以需要分类讨论

## 初始值大于等于$2\pi$

在这种情况下,所有的边取的都是劣弧,也就是开始假设的情况

如果初始就满足大于等于$2\pi$

那么由介值定理,存在R使$f(R)=2\pi$.

此时构造时全部取劣弧,总和恰为 $2\pi$,首尾相接即闭合.

## 初始值小于$2\pi$

在这种情况下,如果所有的边还是取劣弧,凑不到$2\pi$,根据前文所提到的f(R)的单调性,显然不可能得到答案,因此,我们需要让最长边取优弧

所以在这种情况下,我们需要改变上面的求和函数,设
$$T(R)=(2\pi-\theta_1)+\sum_{i=2}^n\theta_i$$
所以这里,我们需要分析后面那个函数,因此设
$$g(R)=\sum_{i=2}^n\theta_i-\theta_1$$
并且满足
$$T(R)=2\pi+g(R)$$
其中,$\theta_1$为最大的弦对应的圆心角

当
$$R=\frac{M}{2}$$
时
$$f(R)=g(R)<2\pi$$
并且M对应的角度是$\pi$

此时最大的这个角度是$\pi$,剩下的角度之和为
$$\sum_{i=2}^n\theta_i=T\left(\frac{M}{2}\right)-\theta_1<2\pi-\pi=\pi$$
所以此时$g<0$

但是当R趋向于正无穷时,根据等价无穷小
$$\lim_{x\to0} \frac{arcsin(x)}{x}=1$$
所以
$$\lim_{R\to\infty} R*g=\lim_{R\to\infty}R\left(\sum_{i=2}^n\theta_i-\theta_1\right)=\sum_{i=2}^na_i-M>0$$
也就是说,当R充分大时,g函数将会从负数变成正数,而且这个函数也是连续的,
那么必然存在一个位置,函数值为0,也就是
$$\sum_{i=2}^n\theta_i=\theta_1$$
因此
$$T(R)=(2\pi-\theta_1)+\sum_{i=2}^n\theta_i=2\pi-\theta_1+\theta_1=2\pi$$
满足角度之和等于$2\pi$

此时构造时最长的取优弧,剩下的取劣弧,构造成功

而且是在圆上构造的,首尾相接转过去逐步构造,一定是凸多边形
# 充分性的证明思路

所以只要满足

>最长的那条线段的长度,小于,其他线段的长度之和

那么必然能构造一个圆内接凸多边形,故能构造凸多边形,充分性得证

所以是充分必要条件
