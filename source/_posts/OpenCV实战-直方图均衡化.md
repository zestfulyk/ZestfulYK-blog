# 直方图均衡化

实现,先计算出现概率,然后求前缀和

灰度为0的还是0,其他的前缀值和乘上最大灰度值,然后给这个值四舍五入作为新值

不改变灰度的出现次数

力图使等长区间内出现的像素数接近相等

# 第一步:彩色变灰色

彩色变灰色:加起来除以3

```C++
Mat img=imread("dark.jpg");
Mat a[3];
split(img,a);
Mat b=(a[0]+a[1]+a[2])/3;
```

# 第二步:统计出现灰度频率

注意点是,灰度图中,每个格子的类型就是`uchar`了,前面的文章中有提到

```C++
vector<double> cnt(260,0);
for(int i=0;i<r;i++){
  for(int j=0;j<c;j++){
    cnt[b.at<uchar>(i,j)]++;
  }
}
```

# 第三步:得到新的像素值

这里先求前缀和,然后除总像素值,最后乘以255再四舍五入

```C++
for(int i=1;i<=255;i++) cnt[i]+=cnt[i-1];
for(int i=1;i<=255;i++) cnt[i]=round((cnt[i]*255)/cnt[255]);
cnt[0]=0;
```

# 第四步:得到新的图

```C++
for(int i=0;i<r;i++){
  for(int j=0;j<c;j++){
    d.at<uchar>(i,j)=cnt[b.at<uchar>(i,j)];
  }
}
```
