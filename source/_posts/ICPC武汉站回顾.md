#### 简单的证明

如果写成排列,`0 1 2 3`

```
0 1
2 3
```

那么每一次交换,实际上就是排列的交换,单次交换只能创造出奇数个逆序对,而目标状态是0逆序对,所以得偶数次交换,因此可以根据这个定义为偶状态和奇状态,只有偶状态是有解的

#### 真正的结论

如果一列全是奇状态的,一次交换后,所有都变成偶状态了,这个是关键,我们可以通过跨轨道,变换成全是偶状态的情况

这里根据这个,转换成01矩阵e,长宽分别为n/2和m/2,

每次转换实现的是,把0和1相互转换,那么,假设行是否转变为`Ai`,列是否转变为`Bj`,满足:
$$A_i\oplus B_i=e_{ij}$$
而且,要是一列满足了,那么全部满足,所以解出一个特解看是否全满足就行了,这样就能检验全部变为偶状态这一步是否成立了

## D

### 思路

这个题目,按照队友的解释方式确实更好理解.

把题目看成是找一颗树,遍历这棵树的结果是输入.

这样就能引出dfs树的关键性质了:

> 任意一条非树边,一定连接某个点和它的祖先/后代,**不存在横叉边**

**横叉边**是指,从某个点到一个既非它子孙节点,也非它祖先节点的边,也就是跑到了别的子树上

分析一下dfs遍历的特点,如果两个点在同一个同一个连通分量内的话,他们都会被遍历到,也就是说,一组连通分量的点是一棵子树

在合法方案中,对任意一条边 `(u,v)`,若 `dep[u]<dep[v]`,那么`u`一定是`v`的祖先

假设去掉了根节点,剩下的点组成的多个连通分量,每一个分量就是一棵子树;下面的子树,去掉子树的根节点,也是一样的

换句话说,遍历到当前点时,去掉已经遍历过的点,剩下的点组成的图中,和当前点在同一连通分量内的一定是当前点的子树

接下来,再次分析dfs遍历的特点,这次对当个点分析

要是邻居有深度更小的,显然会在自己前面访问过,不然根据前面的结论,这些点会作为其子树的一部分,从而深度更大,显然是不对的;所以在合法状态中,深度小的点必然已全访问,顺序重要

要是深度更大的点,一定不是马上访问,否则深度就会变小,所以得先访问深度为自己+1的点

这样逻辑就通顺了,一类是随时可以访问,另外两类有严格的顺序要求,可以发现,直接选择深度小的先访问就是一种合理的构造,然后我们检验构造是否正确就行了

const ll N=2e5+10;
ll dep[N],t[N];
bool vis[N];
vector<ll> g[N];
bool cmp(ll a,ll b){return dep[a]<dep[b];}
void dfs(ll now,ll last){
  vis[now]=1;
  for(int nex:g[now]){
    if(nex==last||vis[nex]) continue;
    t[nex]=t[now]+1;
    dfs(nex,now);
  }
}
void solve(){
  ll n,m; cin>>n>>m;

      cin>>x,g[i].pb(x);

    cout<<-1<<endl;

  }
}

然后关键的一个点是:这个依赖图一定是森林,不存在环,这个可以反证法证明,而且要么全部父指子,要么全部子指父

因为多个子图是孤立的,总方案数可以通过公式计算
$$ans=\frac{n!\prod way_i}{\prod cnt_i!}$$
单个节点的递推满足
$$\frac{(sz[now]-1)!\prod way_i}{\prod cnt_i!}$$
这里还有一个关键观察,正图和反图,逻辑一样,所以可以直接统一化处理

## J

比较容易想到的点是长度为n的序列一定能生成n个n,大于n的必须直接就有

关键点是想到,怎么定一个容易生成的标准,因为每个数字都需要生成和占位.

但是很显然的一点是仅靠这两个量,直接排序,不能直接判定,那么该怎么办呢?

但是我们可以发现,把一些数字放在最后出现是很优的决策,这些数字不会被前面的生成卡位,等那些难的生成了以后,再生成就行了,我称这种性质为适应性强

这样,我们只要给难生成的数字x留下x的空间就行了,前面容易生成的数字所需的位置作为公共位置(设这个长度为m),可以用来借用,因为只要留下这些空间,那些数字自己就能生成这部分序列
$$m+cnt[x]\geq x$$
变形一下
$$m\geq x-cnt[x]$$
可以看出,后面这个值越小,阈值也就越小,所以直接用后面这个比大小,当优先比较的数字就行了

```C++
map<ll,ll> cnt,cntA;
bool cmp(ll a,ll b){
  return a-cnt[a]<b-cnt[b];
}
void solve(){
  ll n; cin>>n;
  cnt.clear(),cntA.clear();
  vector<ll> b(n+1,0),a(n+1,0);
  for(int i=1;i<=n;i++) cin>>a[i],cntA[a[i]]++;
  for(int i=1;i<=n;i++) cin>>b[i],cnt[b[i]]++;
  sort(a.begin()+1,a.end()),sort(b.begin()+1,b.end());
  if(a==b){
    cout<<"YES"<<endl;
    return;
  }
  vector<ll> tmp;
  for(auto[num,_]:cnt) tmp.pb(num);
  sort(tmp.begin(),tmp.end(),cmp);
  ll m=0,p=tmp.size();
  for(int i=0;i<tmp.size();i++){
    if(m+cnt[tmp[i]]>=tmp[i]){
      m+=cnt[tmp[i]];
    }else{
      p=i;
      break;
    }
  }
  for(int i=p;i<tmp.size();i++){
    if(cntA[tmp[i]]<cnt[tmp[i]]){
      cout<<"NO"<<endl;
      return;
    }
  }
  cout<<"YES"<<endl;
}
```
